## eClinic - Frontend

Link - https://eclinicfrontend.vercel.app/

## Prerequisite:

- Node version: 20.xx
- Postgresql: 17
- Environmental variables:
  ```bash
  NEXT_GOOGLE_API_KEY=<GOOGLE_API_KEY>
  NEXT_GOOGLE_EMAIL=<GOOGLE_EMAIL_ADDRESS>
  NEXT_GOOGLE_EMAIL_PASSWORD=<APP_PASSWORD_FOR_GOOGLE_EMAIL>
  NEXT_PUBLIC_BACKEND_BASE_URL=<BACKEND_BASE_URL>
  ```
- You've cloned the [repository](https://github.com/irfiacre/eclinic.git).

#### Getting Started

```bash
# Navigate to cloned repo
cd eclinic/frontend

# Install project dependencies
npm install

# Run deployment server
npm run dev
```
